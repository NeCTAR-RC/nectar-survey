Nectar Dashboard (demo)

Nectar survey popup demo

This page loads the survey popup the same way a Nectar service does: one script plus the <nectar-survey> element. On a host service the popup reads surveys.json from the same folder the script came from; this demo points it at surveys.demo.json instead, which holds an enabled survey open from 13 October to 14 November 2026.

The demo pretends it is 20 October 2026, 10:00, so the popup shows on your first visit whatever today's date is. Change the date below, clear it to use the real date and time, or add ?now= to the address (for example ?now=2026-11-15T10:00). Once the popup has shown, it waits until the next day; "Reset saved state" makes this browser forget every past invitation and checks again.
